Define DBMS in simple terms?
DBMS = Database Management System

DBMS is a software that is used to store, manage and retrieve data from database.
🎯 Example: MySQL, Oracle, MongoDB, SQL Server
✨ Features: • Data Security • Data Sharing • Reduces Redundancy • Backup & RecoveryBCA Exam Tip: DBMS prevents data duplication and provides easy access using SQL queries.
What is Normalization in SQL?
Normalization is a process to organize data in database to reduce redundancy.

Types:
1NF - No repeating groups
2NF - No partial dependency
3NF - No transitive dependency
BCNF - Advanced 3NFUse for clean database design!
